## 机房和线路怎么挑

搬瓦工的机房选择主要围绕线路展开，大致分三层：

- **CN2 GIA**：全程走电信 CN2 独立通道，三网晚高峰表现最稳，代表机房是洛杉矶 DC9、香港、东京、大阪。价格最贵，预算够就选这层。
- **CN2 GIA-E**：GIA 的“可切换”版本，DC6（洛杉矶 CN2 GIA-E）、DC9、JPOS_1（大阪）、EUNL_9（荷兰）等节点可自由迁移，相当于用一份钱买一组线路。
- **CN2 GT / 普通线路**：CN2 GT 出省后走 163 骨干，晚高峰会拥堵；普通 KVM 机房则完全不保证国内方向的路由质量。

一个简单的判断方法：电信宽带用户优先 CN2 GIA/E 线路；联通和移动用户对线路的敏感度低一些，选常规 KVM 机房也有可接受的体验。2026 年搬瓦工陆续在纽约、香港（HK3/HK8）、洛杉矶 DC9 机房上新了 AMD EPYC 处理器加 NVMe SSD 的节点，还新增了新加坡 CN2 GIA 节点，新开机器时可以留意可选机房列表里有没有这些新型号节点。
